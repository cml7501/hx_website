# SPEC：合肥恒星科技官网升级改造（中英双语静态站）

> 状态：**核心交付完成（2026-10-11）**——55 页构建通过；管理服务冒烟、全站视觉与响应式验收、IIS 站点部署运行（http://localhost:8088/）、README 与待补充清单均已交付（工单 01–04 完成，见 `.scratch/hx-website/issues/`）。工单 05（生产上线收尾）等生产托管方案确定。
> 本规格由 2026-10-10 会话共识（两轮 grill 采访 + 用户确认）与已落地实现综合而成。

## Problem Statement（问题陈述）

合肥恒星科技开发有限公司现有官网（www.hfhxkj.com）是 2010 年代初的经典 ASP + GB2312 老站：视觉过时、无移动端适配、仅 HTTP 无 HTTPS、SEO 基础薄弱（无独立 TDK、table 布局）、新闻停更于 2015 年、内容修改必须依赖原建站商。公司无法自行维护内容，海外/展会场景无英文页面，移动端访客体验极差，损害"高新技术企业、ISO 双认证"的品牌形象。

## Solution（解决方案）

以安图生物官网（autobio.com.cn）为风格参照、公司主色改用医疗科技深蓝（#0A4DA3，无 VI 规范时的默认），重建为**中英双语纯静态站点**：内容（产品/新闻/荣誉/招聘/公司信息）全部数据化为双语 JSON，经 Astro 构建输出纯静态 HTML；非技术同事通过**本地内容管理页**（浏览器表单）增删改新闻与产品并一键重新生成网站；站点最终部署于**本机 IIS**。旧站内容（简介全文、9 条公司动态、ISO 证书图、Logo、联系方式、备案号）全部迁移，缺失素材用带标注的占位图，待补充处显式标注【待补充/待校对/待核实】。

## User Stories（用户故事）

**访客 / 潜在客户**
1. 作为医院检验科主任，我想在首页一屏内看懂公司是做什么的（大口号 + 产品分类卡片），以便快速判断是否进一步了解。
2. 作为采购负责人，我想按分类浏览全部 10 个产品型号并查看详细技术参数，以便完成招标前的产品调研。
3. 作为采购负责人，我想在产品详情页一键发起询价并预填意向产品，以便快速取得报价。
4. 作为疾控/畜牧/环保等非临床用户，我想看到 HX-21 按应用领域区分的配置型号，以便选择适配我场景的机型。
5. 作为海外客户/展会访客，我想切换到英文版浏览同等深度的内容，以便评估产品。
6. 作为移动端访客，我希望全站在手机上正常浏览操作（抽屉菜单、单列卡片、可用的表单），以便在任何设备上了解公司。
7. 作为回头客，我想通过新闻中心了解公司近况，并能看到历史公告（公章变更、欺诈警示等存档）。
8. 作为谨慎的买家，我想在"关于我们"看到 ISO9001/ISO13485 证书图、荣誉资质、发展历程和售后承诺，以建立信任。
9. 作为求职者，我想看到招聘岗位、要求与联系途径，以便投递。

**内容编辑（公司非技术人员）**
10. 作为公司文员，我想在浏览器表单里新增一条公司新闻（中英文），无需懂 HTML，保存后点一个按钮网站就更新。
11. 作为公司文员，我想修改产品的一句话定位和特点列表，以便产品信息不再过期。
12. 作为公司文员，我想删除占位新闻，换上真实动态。
13. 作为公司文员，英文不确定时我想只填中文，让网站自动沿用中文显示。

**网站访客的机器（爬虫/浏览器）**
14. 作为搜索引擎爬虫，我想要每页独立的 title/description/keywords、canonical 与 zh/en hreflang 互指，以便正确收录双语页面。
15. 作为浏览器，我希望图片带 width/height 与懒加载，以获得稳定的布局与更快的首屏。

**开发者/维护者**
16. 作为后续接手的开发者，我想把公司 VI 色、统计 ID、表单接口等集中在少数配置点，以便上线前一次性替换。
17. 作为开发者，我想要内容数据与模板彻底分离（改数据不改布局），以便低成本承接内容变更。
18. 作为运维，我想把纯静态产物挂到任意静态托管（本机 IIS、国内虚拟主机、OSS+CDN）而无运行时依赖，以便未来迁移自由。

## Implementation Decisions（实现决策）

**架构与技术栈**
- 技术栈定案：Astro 静态生成（多页、directory 格式、HTML 压缩、@astrojs/sitemap）。产出纯静态文件，零服务器运行时依赖；入选理由是同时满足"非技术维护（数据+重建）+ 每页独立 TDK/SEO + 双语路由 + 任意静态托管"。
- 双语路由：中文为根路径，英文为 `/en/` 前缀；页面组件以 `lang` prop 参数化，中英页面是同一组件的两个实例，不维护两套布局。
- 数据与模板分离：公司信息/产品/新闻/荣誉/招聘/界面文案（含每页 TDK）各为一份 JSON；所有文案字段为 `{zh, en}` 结构，取值时英文缺失回退中文。
- 依赖极简：仅 Astro + sitemap 集成；管理服务为零依赖 Node 内置 http，避免非技术同事环境维护负担。

**内容范围与迁移**
- 页面五类：首页、关于我们（简介/文化/荣誉/历程/视频占位/售后承诺/招聘）、产品中心（分类筛选列表 + 10 个详情页）、新闻中心（行卡列表 + 12 个详情页）、联系我们（信息卡 + 询价表单 + 地图/二维码占位）。每类 ×2 语言。
- 旧站迁移：简介全文（修正原文"科技公关→攻关、为已任→为己任"等错别字）；9 条公司动态双语迁移；转载类行业资讯不迁（版权/时效）；补 3 条【待补充】占位新闻撑版面；发展历程按已知事件搭 5 节点骨架标【待核实】；招聘 4 职位标【待核实】；地址更正为"天达路71号"（2026-10-13 用户二次确认，推翻此前 11 号的说法）。
- 数字亮点（首页）：1993 / 3000+ 用户 / 23% 市占率 / 2000+ 菌种库（数据来自旧站简介，标【待核实】）。
- 旧站真实素材沿用：Logo（378×98）、ISO9001/ISO13485 证书扫描件；其余全部为本地生成的 SVG 占位图（产品/分类/首屏 hero/二维码/地图/新闻缩略图），图内标注"占位图·待替换素材"。旧 Banner 图因自带书法口号与英文水印、与新口号冲突，不再用于首屏（保留在素材目录备用）。

**视觉体系（参照安图、按恒星规模取舍）**
- 单主色贯穿：深蓝 #0A4DA3（CSS 变量 :root 集中定义，VI 色到位改一处全站生效）+ 深蓝页脚 + 浅灰分区；照搬安图的"导航下划线展开、透明导航滚动变白、新闻左图右文行卡、页脚四栏+备案"；舍弃安图的 840px 三级 mega menu（改 560px 两列普通下拉）、1070px 四图轮播（改 ~600px 双图）、杂志式拼贴（改规则 3 列网格）、多语言切换（仅中英）、投资者关系、全站搜索、无限加载。
- 响应式断点 1200/992/768/480；进场动效（IntersectionObserver 上浮）、卡片 hover 微放大、数字滚动计数；`prefers-reduced-motion` 全关。
- 首页口号：「为微生物检验精准服务」主标 +「科技永恒 · 服务创星」副标（沿用旧站经营理念）。

**交互与集成配置点（上线前集中替换）**
- 询价表单：前端完整校验（必填/电话格式/邮箱格式、行内报错）；提交行为由 `window.HX_FORM_ENDPOINT` 决定——留空为演示模式（校验通过即提示"演示模式"成功），填接口地址则真实 POST JSON；产品详情页"在线询价"携 `?product=型号` 预选下拉。
- 百度统计：`window.HX_BAIDU_TONGJI_ID` 留空不加载、填 ID 即注入 hm.baidu.com 脚本。
- 本地管理服务（`npm run admin`，127.0.0.1:4173）：新闻/产品的表单式增删改（双语字段、英文留空回退中文、正文空行分段）；PUT 前服务端校验（slug 格式/唯一、日期格式、必填中文标题、正文非空）；"保存并重新生成网站"按钮依次保存数据并触发重新构建，IIS 无需重启即可见新内容；另提供询价接收端点与询价记录查看（管理页内 Tab）。
- IIS 部署：构建产物目录直接作为 IIS 站点物理路径；创建过程以提权脚本完成（当前 shell 无 IIS 管理权限，部署时经 UAC 确认）。

## Testing Decisions（测试决策）

- 好的测试只验证**外部可见行为**（HTTP 响应、渲染结果、API 契约），不测组件内部结构与 CSS 细节。
- 缝 1（最高缝，主缝）：**静态站点 over HTTP**。对 preview/IIS 服务后的页面做断言：关键页面 200；每页独立 TDK、canonical、hreflang（zh-CN/en/x-default）三向互指；图片含 lazy 与宽高；导航/页脚关键链接存在；双语页面互指正确。浏览器级交互（轮播、分类筛选、表单校验与提交态、抽屉菜单）通过浏览器自动化做冒烟。
- 缝 2：**管理服务 HTTP API**。对 PUT /api/data/* 的校验拒绝（坏 slug、缺标题）、合法保存后重建产物更新、询价端点落盘记录做契约测试。
- 无既有测试先例（新仓库）；上述断言以 curl/grep 脚本 + 浏览器截图评估的形式建立，未来可固化为 CI 脚本。
- 视觉验证：关键页面（首页/产品列表/产品详情/联系/英文首页/手机端首页）截图并由视觉评审把关，布局回归以截图对比为准。

## Out of Scope（明确不做）

- 生产托管选型与迁移（含 HTTPS、ICP 备案接入变更）——部署环境定了再做。
- 旧站 `.asp` URL 的 301 跳转映射——依赖生产环境（IIS rewrite / 新主机配置）。
- 询价表单接真实收件通道（企业邮箱/SMTP/第三方表单服务）——接口占位已留，上线前接入。
- 百度统计实际启用（建站点、填 ID）。
- 英文文案的人工校对与润色（当前为机器初稿，标【待校对】）。
- 真实素材替换（产品图、二维码、地图、企业视频、高清证书、VI 色规范）。
- 招聘/荣誉内容的管理页编辑（低频，README 注明走开发）；管理服务的多用户鉴权（本机单用户场景）。
- IE11 兼容（仅现代浏览器：Chrome/Edge/Firefox/Safari 近两年版本及 Chromium 内核国产浏览器）。
